# Controle Financeiro — APK Android

Projeto Android baseado no `index.html` enviado pelo usuário.

## Gerar online

Este projeto pode ser enviado a um serviço de build Android online ou a um repositório GitHub com Actions.

## Gerar localmente

Abra no Android Studio e execute **Build > Generate App Bundles or APKs > Generate APKs**.

O app usa WebView, armazenamento DOM/localStorage e acesso à internet para recursos externos usados pelo HTML.
